# Emulator build evidence — 2026-09-12

## Scope

The Linux/WSL simulator working clone was synchronized to source commit
`9344c07b3f2d0df286a1962f2ab80b5a61edcb80`. This record covers native
compilation only. It does not claim a physical X4 Pro boot, panel orientation,
touch, frontlight, PSRAM, sleep/wake, recovery gesture, SD access, or backup
restore result.

`cmake -S test -B build-host -DCMAKE_BUILD_TYPE=Release`, followed by
`cmake --build build-host -j2` and `ctest --test-dir build-host
--output-on-failure`, completed with **211/211** passing tests.

## Limits

The three successful builds prove that the configured controller code paths
compile against the pinned simulator. They do not address the X4 Pro's zero
IRAM headroom or establish that any physical controller variant is safe to
flash. The physical matrix and recovery drill in `physical-validation.md`
remain release gates.
