# Physical evidence records

This directory intentionally contains no fabricated panel or recovery result.
When a physical test occurs, create the matching record named by
`physical-validation.md` and include:

- device identification with sensitive serial data redacted;
- detected controller path and test date;
- exact ChinesePoint source commit and application SHA-256;
- preflight recovery result; observed panel, reader, CJK, dictionary, export,
  and Anki outcomes; and
- photographs or logs stored in a durable location, with their relative path
  or public reference.

Mark only a directly observed test `passed`. A simulator screenshot, an older
firmware, or another panel is not a substitute.
